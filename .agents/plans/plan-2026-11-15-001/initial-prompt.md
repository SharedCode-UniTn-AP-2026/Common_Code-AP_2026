> through a chat interface, alongside manual development, so there is no single

Task: write the integration tests for `Cell` and `Direction` in
`src/geometry/tests/cell.rs`.

Requests made to the AI chat during development:

1. Proofread and correct the wording of some (not all) of the comments in the
   test file.
2. Write the "Documented panics" section of the tests, starting from the
   `# Panics` documentation in `src/geometry/src/cell.rs`, since those tests are
   mechanical.
3. Write the doc comments for the helper functions, constants and strategies
   used by the tests.
4. Give an opinion on the usefulness of some tests, in order to remove redundant
   or useless ones.

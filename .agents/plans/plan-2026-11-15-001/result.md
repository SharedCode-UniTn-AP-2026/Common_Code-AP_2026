# Result: property-based tests for `Cell` and `Direction`

## Authorship

The test suite was designed and written by the user. No coding agent was used:
an AI chat assistant was consulted during development, and this folder was
written by hand afterwards to document that use.

The AI was used for:

- **Comment proofreading.** Correcting the wording of some (not all) of the
  comments in `src/geometry/tests/cell.rs`. The content of the comments is the
  user's.
- **Documented panics section.** Writing the tests under `// --- Documented
  panics ---`, derived from the `# Panics` sections of the doc comments in
  `src/geometry/src/cell.rs`. These tests are mechanical: one `#[should_panic]`
  test per documented panic, plus a boundary test that must not panic.
- **Doc comments for test helpers.** Writing the doc comments of
  `ALL_DIRECTIONS`, `any_cell`, `MAX_MAP_RADIUS`, `map_cell`,
  `distance_another_formula` and `is_strictly_ascending`.
- **Test review.** Giving an opinion on the usefulness of some tests. The user
  used it to decide which tests were redundant or useless and removed them; the
  final decision on each test was the user's.

All AI output was reviewed by the user before being kept.

## Changes

- Added `proptest = "1.12.0"` as a dev-dependency in `src/geometry/Cargo.toml`
  (and the corresponding `Cargo.lock` update).
- Added `src/geometry/tests/cell.rs` with 19 tests:
  - 9 property-based tests (distance, neighbours, ring, disc, no overflow for
    cells inside a `Map`).
  - 2 exhaustive tests on `Direction::relative_angle`.
  - 1 test on opposite corners at the coordinate limit.
  - 7 tests on documented panics and their boundaries (`s`, `neighbour`,
    `disc`, `ring`).
- `proptest-regressions/geometry/tests/cell.txt` was generated by `proptest`
  during development.

## Validation

- `cargo test -p ap-2026-common-code-geometry --test cell`: 19 passed, 0 failed.
- `cargo fmt --all -- --check`: passed.
- `cargo clippy -p ap-2026-common-code-geometry --tests -- -D warnings`: passed,
  no warnings.

## Questions and answers

The AI was used through a chat, so the exact conversation is not reproduced
here. The questions asked were, in summary:

- **Q:** Can you correct the wording of these comments?
  **A:** The AI suggested corrected versions; the user kept some of them.
- **Q:** Can you write the tests for the documented panics, starting from the
  documentation of `cell.rs`?
  **A:** The AI wrote the tests in the "Documented panics" section, which the
  user reviewed.
- **Q:** Can you write the documentation for the helper functions and types
  used by the tests?
  **A:** The AI wrote the doc comments, which the user reviewed.
- **Q:** Are these tests useful, or are some of them redundant?
  **A:** The AI gave its opinion on each test; the user removed the ones they
  judged redundant or useless.
